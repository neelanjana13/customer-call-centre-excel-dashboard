# Customer Call Centre Analytics Dashboard – Excel

## Project Overview

This project analyzes customer call centre data using Microsoft Excel to evaluate call volume, revenue, customer satisfaction, and representative performance.

The project includes data preparation, PivotTable analysis, interactive filtering, KPI development, and dashboard visualization.

## Objectives

- Analyze overall call centre performance
- Track call volume and purchase amount
- Compare representative performance
- Analyze customer satisfaction ratings
- Compare male and female callers
- Analyze call activity by month and day of the week
- Evaluate representative-level performance
- Analyze customer activity across different cities

## Dataset

The dataset contains 1,000 customer call records.

Key fields include:

- Call Number
- Customer ID
- Call Duration
- Representative
- Date of Call
- Purchase Amount
- Satisfaction Rating
- Fiscal Year
- Day of Week
- Customer Gender
- Customer Age
- Customer City

## Tools Used

- Microsoft Excel

## Dashboard Features

The dashboard includes:

## Key Insights

- The call centre processed 1,000 customer calls.
- The calls generated a total purchase amount of $96,623.
- The overall average customer satisfaction rating was approximately 3.9 out of 5.
- 307 calls received a five-star rating.
- Representative performance varied in terms of call volume and purchase amount.
- Customer activity and purchase amounts differed across Cincinnati, Cleveland, and Columbus.
- Monthly and day-of-week trends showed variations in call activity.

## How to Use

1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Navigate to the `Customer Centre Report` sheet.
4. Use the Representative slicer to filter the dashboard.
5. Explore the KPIs, charts, and customer-level analysis.
